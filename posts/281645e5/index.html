GitHub + PicGo + jsDelivr 图床配置教程

发表于2026-05-09|更新于2026-05-11|基础设置
|浏览量:

核心优势

推荐指数：★★★★★

  1. 博客源码仓库轻量化
    图片单独放独立仓库，Hexo 主仓库只存文章代码，体积小、git clone/ 拉取同步、部署速度飞快，不会被大量图片拖慢。
  2. 国内访问速度远优于直接放 source/img
    用 jsDelivr 公共 CDN 加速，国内节点稳定，比直接加载 GitHub Pages 原生图片快很多，不易加载失败、打不开。
  3. 图片与文章解耦，好维护
    删文章不用去源码里找对应图片手动清理；以后换博客主题、换 Hexo 框架、换域名，图片链接不用改，全部通用。
  4. 多设备写博客极其方便
    换电脑只需拉取博客源码仓库，不用同步一大堆图片；任意电脑装 PicGo 即可上传插图写文章。
  5. 免费永久稳定、无容量限制
    GitHub 公开仓库免费不限量，jsDelivr CDN 免费无流量限制，无广告、不压缩画质、不跑路。
  6. 自动生成标准 Markdown 链接
    不用手动拼路径、不用怕相对路径出错，上传完直接复制粘贴就能用，适配所有 Hexo 主题。

准备工作

  1. 已有 GitHub 账号（部署 Hexo 必备）
  2. 安装 PicGo 客户端
    下载：https://github.com/Molunerfinn/PicGo/releases
  3. 新建独立专用图床仓库，不和 Hexo 博客源码仓库混在一起

主要步骤

  1. GitHub 新建图床仓库
    GitHub 右上角「+」→ New repository
    仓库名：blog-images（自定义即可）
    勾选 Public（必须公开，jsDelivr 才能访问）勾选 Add a README file（可选） → 创建仓库
  2. 生成 GitHub 个人 Token
    头像 → Settings → 底部 Developer settings
    Personal access tokens → Tokens(classic)
    Generate new token(classic)
    备注随便填，过期选 No expiration 永久有效
    权限只勾选 repo
    拉到最下方生成，立刻复制保存 Token（只显示一次，错过需重新生成）
  3. PicGo 关键配置
    左侧 → 图床设置 → GitHub按下面填写：
配置项 填写内容示例
图床配置名 blog-github（随便填，必填）
设定仓库名 wmkx/blog-images 格式：用户名 / 仓库名
设定分支名 main
设定 Token 粘贴刚才复制的 GitHub Token
设定存储路径 image/
设定自定义域名 https://cdn.jsdelivr.net/gh/wmkx/blog-images
  1. 填完点「确定」→ 设为默认图床 → 完全关闭 PicGo 重新打开生效。
